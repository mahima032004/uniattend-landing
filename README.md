# UniAttend – Landing Page

Landing page for **UniAttend**, an AI-powered attendance app for universities.

🔗 **Live site:** https://mahima032004.github.io/uniattend-landing/

## Features
- 📸 Face recognition attendance from classroom photos
- 🎙️ Voice attendance
- 👩‍🏫 Teacher portal to create subjects and view records
- 🎓 Student portal with Face ID login and attendance tracking

## Tech
HTML, CSS, JavaScript, hosted on GitHub Pages.
